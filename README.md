# media.jamesgunaca.com

GitHub Pages site serving the monthly Product Management Jobs Report and media
assets for jamesgunaca.com.

- `index.html` — always the LATEST monthly report (self-contained: fonts, logo and
  charts are inlined; no external dependencies).
- `reports/<month>-<year>.html` — permanent archive copy of each month.
- `social/` — Open Graph / social sharing images.
- `img/` — newsletter and media images (see img/README.md).
- `CNAME` — custom domain binding for GitHub Pages (media.jamesgunaca.com).

The public page for readers is https://jamesgunaca.com/jobs-report (Squarespace),
which embeds this site. Monthly updates: replace `index.html`, add the archive
copy under `reports/`, add the month's OG image under `social/`.

Generated by the JOB_REPORT_SKILL_v4 workflow.
